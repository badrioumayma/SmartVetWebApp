# 🐾 SmartVet – IoT Animal Health Monitoring System

## 📌 Overview
SmartVet is an **IoT-based web application** that enables real-time monitoring and management of animal health. By combining smart sensors with a modern web dashboard, the system helps track animals' vital signs and provides actionable insights for better care.

---

## 🚀 Features

- 📊 **Interactive Dashboard**  
  View real-time health data and summaries in a clean interface.

- 🐶 **Animal Management**  
  Add and manage animals (name, age, weight, type: cat, dog, cow, sheep).

- ❤️ **Real-Time Monitoring (IoT)**  
  Track animals’ vital signs using connected sensors:
  - Temperature  
  - Heart rate  
  - Activity / movement  

- 📈 **Analytics & Statistics**  
  Visualize historical data and identify health trends.

- 🔔 **Smart Alerts**  
  Get notified when abnormal conditions are detected.

- 📍 **GPS Tracking**  
  Monitor animal location in real time.

- 📱 **Responsive Design**  
  Works on desktop and mobile devices.

---

## 🌐 IoT Integration

SmartVet uses **Internet of Things (IoT)** technology to connect physical sensors to the platform:

- Sensors collect animal data continuously  
- Data is transmitted via microcontrollers (e.g., NodeMCU)  
- Backend processes and stores the data  
- Frontend dashboard displays it in real time  

This enables **continuous monitoring and early detection of health issues**.

## 🎯 Objective

The goal of SmartVet is to improve animal healthcare by combining **IoT and web technologies** to:
- Monitor animal health continuously  
- Detect issues early  
- Provide real-time insights
